# 🎓 Student Enrollment Data Analysis Dashboard

## 📌 Project Description

Student Enrollment Data Analysis Dashboard is a Python-based web application developed using Streamlit.

It helps to analyze and visualize student enrollment data using interactive charts, filters and search functionality.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Plotly

## ✨ Features

- 📊 Student enrollment dashboard
- 🔍 Student search by Name or Student ID
- 🏫 Department-wise analysis
- 👨‍🎓 Gender-wise analysis
- 📚 Year-wise analysis
- 📋 Category-wise analysis
- 🧹 Data cleaning
- 🔎 Interactive filters
- 📥 Download filtered student data as CSV
- 📄 Student details table
